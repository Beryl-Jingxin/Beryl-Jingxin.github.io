01 / OPEN SOURCE

PyExoCross

An open source Python framework for processing atomic and molecular line lists. It calculates thermodynamic and radiative quantities, stick spectra, and absorption and emission cross sections under LTE and non-LTE conditions.

GitHubDocumentationPyPI

02 / DATABASE

ExoMolHR

A high resolution molecular spectroscopic database and web platform. It provides empirically refined line positions, uncertainty-aware transition selection, and tools for querying, visualising, and downloading spectral data.

Database website
03 / SPECTRAL INFERENCE

Physics-informed component identification

Ongoing work on component identification and physical parameter inference for strongly blended atomic and molecular spectra. The research tests identifiability across physical conditions, resolution, and noise.
